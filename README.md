# 👚 Virtual Outfit Studio


### AI-Powered Virtual Try-On Using Computer Vision and Generative AI

AI Fashion Fitting is an advanced **Computer Vision and Generative AI** web application that allows users to virtually try different garments on a person using two images: a **person image** and a **garment image**.

The system uses a **Virtual Try-On (VTON)** model to generate a new image in which the selected garment is realistically fitted onto the person while attempting to preserve the person's identity, pose, body structure, and visual appearance.

---

## ✨ Features

- 📸 Upload a person image
- 👕 Upload a garment or outfit image
- 🧠 AI-powered virtual try-on
- 🧍 Supports different body proportions and poses as supported by the underlying VTON model
- 👗 Supports upper-body garments and dresses
- 🎨 Garment-aware image generation
- 🔄 Random seed generation for different results
- ⚙️ Adjustable denoising steps
- 📷 Webcam support for capturing a person image
- 🖥️ Modern responsive web interface
- 📊 Generation status and progress feedback
- 🔁 Generate multiple variations
- 🧹 Reset and try another outfit
- 🔐 No API credentials exposed in frontend code

## 🚀 How It Works

The application follows a computer-vision-based virtual try-on pipeline:

```text
Person Image
      │
      ▼
Image Preprocessing
      │
      ▼
Human / Pose Analysis
      │
      ▼
Garment Processing
      │
      ▼
Garment Conditioning
      │
      ▼
Generative VTON Model
      │
      ▼
Virtual Try-On Image
```

The application does **not** simply paste or resize the clothing image over the person. The final result is generated by a dedicated virtual try-on model.

## 🖥️ User Workflow

### Step 1 — Upload Person

Upload a photograph of the person who will wear the garment.

Recommended:

- One clearly visible person
- Good lighting
- Reasonably clear image
- Person not heavily obstructed

### Step 2 — Upload Garment

Upload the clothing or outfit that should be applied.

Examples:

- T-shirt
- Shirt
- Top
- Blouse
- Jacket
- Dress

A clear garment/product image generally produces better results.

### Step 3 — Select Garment Category

Choose:

```text
Upper Body
Lower Body
Dress
```

The category provides additional information to the virtual try-on pipeline.

### Step 4 — Generate

Click:

```text
✨ Generate Virtual Try-On
```

The application sends the images to the configured VTON model.

### Step 5 — View Result

The generated image is displayed in the result panel.

Users can change the seed and generate another variation.

## ⚙️ Generation Parameters

### Seed

The seed controls the random generation process.

You can either:

- Use a fixed seed
- Enable random seed generation

Different seeds may produce different generated results.

### Denoising Steps

Denoising steps control the diffusion generation process.

The application provides a configurable range so users can experiment with generation quality and processing time.

### Auto Crop

Auto Crop can be enabled when the input image requires automatic cropping before VTON processing.

## 🤖 AI Model

This project uses the **IDM-VTON** virtual try-on approach through a Gradio-compatible inference interface.

IDM-VTON is designed specifically for high-fidelity virtual try-on and uses computer-vision information such as human parsing and pose-related representations to condition garment generation.

The application communicates with the hosted model using the Python `gradio_client`.

```text
Python Application
       │
       ▼
Gradio Client
       │
       ▼
IDM-VTON
       │
       ▼
GPU Inference
       │
       ▼
Generated Try-On
```

## ⚠️ Limitations

Virtual try-on is a generative AI task, so the output may vary depending on the input images and available model resources.

Possible limitations include:

- Difficult poses may produce artifacts
- Occluded body parts may be reconstructed incorrectly
- Hands and arms can sometimes contain visual artifacts
- Very low-resolution images may produce poor results
- Complex garment patterns may not be perfectly preserved
- Extreme camera angles may reduce accuracy
- Multiple people in an image may not be supported reliably
- Public GPU services may have usage or queue limitations

The application should therefore be considered an **AI-powered visualization system**, not an exact physical fitting measurement system.
